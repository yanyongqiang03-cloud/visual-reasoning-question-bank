## 必须说明的局限

小样本、同一来源、题库公开造成泄漏风险、人工真值分歧、单人评分主观性。准确率不能推广到脂滴图像或临床任务。仅提供元数据后答对细胞类型/染料，不能算纯视觉识别能力。
