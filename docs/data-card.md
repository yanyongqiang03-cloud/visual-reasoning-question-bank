# 数据卡

- 来源：https://bbbc.broadinstitute.org/BBBC001
- 数据版本：BBBC001v1；下载日期：2026-10-08。
- 权利人：David Root、Anne Carpenter；许可：CC BY-NC-SA 3.0。
- 内容：HT29 人结肠癌细胞，6 个视野；本版本只提供 Hoechst 33342 核染色通道。
- 元数据：所有视野均接受同一 RNAi reagent Rock1_1885_k27。不能将文件末尾编号当作不同处理组。
- 512×512，8 位 TIFF；PNG 为逐像素格式转换。
- 两人计数参考均值依次为 356、339、421.5、330.5、465.5、249。
- 不提供：核轮廓、脂滴标注、RUNX2 干预、对照组、显著性检验。
- 原始图压缩包：https://data.broadinstitute.org/bbbc/BBBC001/BBBC001_v1_images_tif.zip
- 原始计数：https://data.broadinstitute.org/bbbc/BBBC001/BBBC001_v1_counts.txt

本项目贡献是任务设计、证据边界规则及后续评测，不是采集这些图像或重新生成原始计数真值。用途为非商业学习展示；企业商业用途需另选许可合适的数据或另行获权。
