# Bencher 视觉推理题样例

根据用户提供的岗位说明，本项目主展示改为通用视觉推理。重点是图像信息、明确规则、可复算步骤与唯一答案，不要求生物学题材。

## 材料

| 素材 | 题目 | 能力 |
|---|---|---|
| [符号网格](../assets/symbol-grid.svg) | V01、V02 | 目标识别、计数、空间关系 |
| [加权路线](../assets/route-map.svg) | V03、V04 | 路径分析、条件筛选 |
| [库存表](../assets/inventory.svg) | V05、V06 | 图文信息提取、多步计算 |

完整题面、解题步骤、标准答案：[visual-reasoning.csv](../data/visual-reasoning.csv)。这些是 AI 辅助制作的原创示意素材，不是实拍或采集的实验图片。素材与题库采用项目 CC BY-NC-SA 3.0 许可。若平台要求商业使用授权，需要作者审定权利并调整原创部分许可；第三方细胞图像许可不能随之更改。

## 质检

1. 原图渲染后核对符号颜色、位置、边权和表格数字；检查字体可读性。
2. 检查题面没有依赖常识补充的隐含条件。路径题规定双向、交叉不成节点、是否允许重复节点。
3. 独立复算标准答案；路线最小值需排除其他可行路径。
4. 记录复核姓名、日期及修改意见。当前 pending_author_review；不要将 AI 辅助样例声称为本人独立完成。
5. 测试时只向模型发送 PNG 和题面，禁止发送 SVG 源码、文件中标准答案或整个仓库。SVG 可编辑源文件供审核者核验。

## 面试可讲的设计理由

V01 用相同颜色不同形状及相同形状不同颜色作为干扰；V02 要求同时理解行号和直接相邻。V03 的最优路径不是边数最少路线；V04 将最优化改为带约束的路径计数。V05 和 V06 使用同一张表考察不同规则，避免只做数字识别。
